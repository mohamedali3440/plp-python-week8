\# Personal Mini-Toolkit



\## Project Description



The Personal Mini-Toolkit is a Python menu-driven program that provides three useful tools in one application. The tools are a Number Guessing Game, a To-Do List, and a Simple Calculator. The program uses variables, input and output, conditionals, loops, lists, and f-strings. The main menu continues running until the user chooses the Quit option.



\## Tools Included



\### 1. Number Guessing Game



The user tries to guess a randomly selected number between 1 and 10. The program gives hints when the guess is too high or too low and counts the number of attempts.



\### 2. To-Do List



The user can add tasks, view tasks, and remove tasks. The tasks are stored in a Python list that changes while the program is running.



\### 3. Simple Calculator



The calculator performs addition, subtraction, multiplication, and division. It also prevents division by zero.



\## How to Run



1\. Make sure Python is installed on your computer.

2\. Open PowerShell or a terminal.

3\. Navigate to the project folder.

4\. Run the following command:



```text

python toolkit.py

```



5\. Choose a tool from the menu and follow the instructions.

\## Reflection



The hardest part of the project was connecting all three tools to one menu-driven program. The menu loop needed to return to the correct place after each tool finished. One bug that took the longest to fix was making sure invalid choices did not crash the program. Testing the To-Do List helped me understand how a list can change while a program is running. I also learned how conditionals can be used to handle different calculator operations. Testing division by zero showed me the importance of handling invalid situations safely. With one more week, I would add more tools such as a countdown timer and a name formatter. I would also improve the design of the menu and add more input validation.
